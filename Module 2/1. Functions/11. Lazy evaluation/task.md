# Одно из частых применений генераторов - это реализация бесконечных последовательностей. Реализуйте в файле src/solution.py функцию get_fibonacci(), которая генерирует числа последовательности Фибоначчи. Функция не принимает аргументов, и последовательность у неё бесконечная. Напомним, что правило, по которому формируется последовательность, можно записать так:
# первые два числа
a, b = 0, 1

# последующие
a, b = b, a + b
За один шаг генератор отдаёт через yield одно число, в правиле выше это a. Первым идёт 0.

## Пример использования:

```python
fib = get_fibonacci()

for x in fib:
    print(x)
    if x > 10:
        break

# => 0
# => 1
# => 1
# => 2
# => 3
# => 5
# => 8
# => 13
```

## Подсказки

- Помните, что yield не заканчивает выполнение функции, и после него можно продолжить вычисления
